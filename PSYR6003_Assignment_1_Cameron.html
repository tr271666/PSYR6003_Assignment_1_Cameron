Avengers_dataset %>% count(superpower) #seeing an issue with the original dataset. One of the superpower responses is "yes" instead of yes. the "yes", has iq, and we can therefore include it in the iq/superpower analysis. so we must clean it BEFORE actual analysis.

Avengers_dataset_clean_superpower <- Avengers_dataset %>%
  mutate(
    superpower = gsub('"', '', superpower))# getting rid of the additional "" in the yes variable. first argument is the pattern we want to fix ('"' (notice that ' is surrounding ")), and second argument is what we want to replace it with('' (we are replacing it with nothing)). ?gsub help page. dont need it for this specific case, but other functions that could be helpful for future projects: "tolower(superpower)" (converts everything to lowercase), OR "trimws(superpower)" (removes extra spaces at beginning or end of name/string)

"is.na(iq)" Checks whether the IQ value is missing. the "!" essentially means "not", so "!is.na(iq)" means that the function is checking if the value is NOT missing. so, this function is basically keeping all of the rows that match my conditions (not missing for iq and suopor power), and eliminating/filtering any others.
